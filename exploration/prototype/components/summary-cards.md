# Summary Cards Component — PortfolioSummaryCards.tsx

Created at `investment_screener/frontend/src/components/PortfolioSummaryCards.tsx`.

4-card grid layout:
1. **YTD Performance** — % change as hero number, CAD and USD dollar changes below
2. **Total Market Value** — CAD as hero, USD and position count below
3. **Book vs Market** — unrealized gain/loss %, USD and CAD amounts below
4. **Exchange Rate** — live USD/CAD rate, Jan 1 comparison rate

Green/red color coding for positive/negative values. Luxury dark mode styling with slate-900 cards.
