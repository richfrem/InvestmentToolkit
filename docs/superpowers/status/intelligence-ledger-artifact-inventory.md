## Summary by category

- **Authoritative (must never be treated as disposable):** `observations.jsonl`,
  `research/archive/*.md`. Both now committed and durable.
- **Derived / rebuildable (safe to regenerate, must stay gitignored):**
  `intelligence.sqlite` and its FTS shadow tables.
- **Derived but committed by design (not a violation — matches `docs.ts`'s current
  read-from-disk contract for canonical filenames):** the 144 `.summary.md`/`.timeline.md`
  files.
- **Legacy and unrelated to this migration, needing its own future review:** the 72 bare
  `{TICKER}.md` canonical files.
- **Consumer data with a small number of known, documented gaps:** the projection pointer
  fields.
