# Task 0002: TradingView Pine Script Analysis Capabilities

## Objective
Add new skills and script capabilities to the `tradingview` plugin to empower the AI agent to:
1. Open and interface with TradingView.
2. Generate and save its own custom Pine Script indicators.
3. Perform autonomous technical analysis using these indicators.
4. Advise the user on portfolio actions (initiate, accumulate, trim, exit) based on the analysis.

## Acceptance Criteria
- [ ] New Pine Script generation script/tool is added to the `tradingview` plugin.
- [ ] Agent can inject and save Pine Scripts into TradingView via CDP automation.
- [ ] Agent can read back indicator signals and chart data from the injected Pine Scripts.
- [ ] A new technical analysis advisory skill is created that maps indicator signals to portfolio actions (start, accumulate, trim, exit).
- [ ] The `tradingview` plugin documentation and SKILL.md files are updated for the new capabilities.
